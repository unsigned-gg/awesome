# Contributing to Awesome Unsigned

Thank you for your interest in contributing to **Awesome Unsigned**!

## Guidelines

1. **Relevance**: Submissions should be open-source tools, runtimes, orchestrators, or infrastructure relevant to autonomous agent systems, bare-metal computing, and deterministic plumbing.
2. **Quality**: Projects should be actively maintained, have clear documentation, and adhere to sound engineering and security practices.
3. **Format**: Follow the existing Markdown link format:
   `- [name](url) — Brief description of the project.`
4. **Commits**: Use Conventional Commits (`feat:`, `fix:`, `docs:`).

## Submission Process

1. Fork the repository.
2. Create a feature branch (`git checkout -b feat/add-my-tool`).
3. Add your project under the appropriate section in alphabetical order.
4. Commit your changes and submit a pull request.
